 راهنمای نصب «کارنما» روی GitHub Pages — هاست رایگان
════════════════════════════════════════════════════════════

GitHub Pages یک هاست رایگان و همیشه‌فعال است و کارنما
روی آن کامل اجرا می‌شود. فقط یک تفاوت با نسخه هاست PHP
دارد که در پایین توضیح داده شده.

────────────────────────────────────────────
 مراحل نصب (حدود ۵ دقیقه، بدون نصب هیچ برنامه‌ای)
────────────────────────────────────────────
مرحله ۱) در github.com یک حساب رایگان بسازید (اگر
ندارید) و با ایمیل تأیید کنید.

مرحله ۲) روی دکمه سبز «New repository» کلیک کنید:
  • Repository name: مثلاً karnama
  • انتخاب Public ( Pages رایگان فقط برای مخزن
    عمومی است — نگران نباشید: داده‌های شما داخل
    مخزن قرار نمی‌گیرد، فقط کد برنامه است.)
  • دکمه «Create repository»

مرحله ۳) در صفحه بعد روی لینک
  «uploading an existing file» کلیک کنید.

مرحله ۴) محتویات این فایل زیپ را (همه فایل‌ها و پوشه‌ها:
  index.html و پوشه‌های js و css و assets و samples و
  بقیه فایل‌ها) با ماوس بکشید و داخل کادر بندازید.
  مرورگر کروم/اج پوشه‌ها را هم می‌پذیرد.
  صبر کنید تا آپلود تمام شود.

مرحله ۵) دکمه سبز «Commit changes» را بزنید.

مرحله ۶) از منوی بالای مخزن روی «Settings» کلیک کنید،
  از منوی چپ «Pages» را انتخاب کنید، سپس:
  • Source: «Deploy from a branch»
  • Branch: main و پوشه /(root)
  • دکمه Save
  چند دقیقه صبر کنید تا آدرس سایت بالای همان صفحه
  سبز شود. آدرس شما چیزی شبیه این است:

      https://نام-کاربری.github.io/karnama/

مرحله ۷) تمام! آدرس را در گوشی یا کامپیوتر باز کنید.
  چون آدرس https است، می‌توانید از منوی مرورگر کروم
  «Add to Home screen» را بزنید تا کارنما مثل یک اپ
  روی گوشی نصب شود و آفلاین هم باز شود.

────────────────────────────────────────────
 به‌روزرسانی برنامه در آینده
────────────────────────────────────────────
در صفحه مخزن، دکمه «Add file → Upload files» را بزنید،
فایل‌های جدید را آپلود و «Commit changes» بزنید. چند
دقیقه بعد سایت به‌روز می‌شود. (اگر تغییرات را دیدید،
یک بار صفحه را با Ctrl+F5 کامل تازه کنید.)

────────────────────────────────────────────
 تفاوت مهم با نسخه هاست PHP
────────────────────────────────────────────
GitHub Pages فقط فایل‌های ثابت را سرو می‌کند و PHP
اجرا نمی‌کند؛ بنابراین server.php آنجا کار نمی‌کند:

  ✓ همه امکانات برنامه: ثبت کارکرد، تقویم، گزارش‌ها،
    خروجی اکسل، تم تیره/روشن، اپ گوشی (PWA)، آفلاین
  ✗ همگام‌سازی روی سرور و بین چند دستگاه — فعال نیست

یعنی داده‌ها فقط در حافظه همان مرورگر ذخیره می‌شوند.
برای جابه‌جایی داده بین دستگاه‌ها (مثلاً از کامپیوتر به
گوشی) از تنظیمات → «خروجی بکاپ» فایل JSON بگیرید و در
دستگاه دیگر از «بازیابی از فایل» وارد کنید. (در صفحه
تنظیمات، بخش «آینه روی هارد دیسک» حالت «غیرفعال» را
نشان می‌دهد که طبیعی است.)

اگر روزی خواستید همگام‌سازی هم باشد، همان نسخه PHP را
(karnama-web.zip و راهنمای README-HOST.txt) روی یک
هاست PHP نصب کنید.

────────────────────────────────────────────
 نکته‌های کاربردی
────────────────────────────────────────────
  • محدودیت حجم: مخزن تا ۱ گیگابایت — کارنما حدود
    ۱.۲ مگابایت است، خیلی جا دارید.
  • دسترسی در ایران: سایت github.com باز می‌شود اما
    آدرس github.io گاهی کند یا ناپایدار گزارش می‌شود.
    اگر برای شما باز نشد، می‌توانید یک دامنه شخصی به
    سایت وصل کنید (Settings → Pages → Custom domain).
  • حریم خصوصی: چون مخزن عمومی است، کد برنامه برای
    همه قابل دیدن است؛ اما داده‌های کارکرد شما فقط در
    مرورگر خودتان است و جایی آپلود نمی‌شود.
